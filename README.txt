DEM Consulting website

Files
  index.html       Home
  about.html       About
  services.html    Services
  experience.html  Experience (case studies with filters)
  contact.html     Contact and consultation form
  styles.css       Shared styles for every page
  site.js          Shared scripts: menu, map background, filters, contact form
  vercel.json      Makes addresses show as /about instead of /about.html

Upload: put all of these files at the top level of your GitHub repository (not inside a folder) and commit. Vercel redeploys automatically.

Editing: to change text on one page, edit that page's .html file. To change colours or fonts everywhere, edit styles.css.
The contact form access key is near the top of the form section in site.js.
